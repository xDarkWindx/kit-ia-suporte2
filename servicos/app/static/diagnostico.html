Ver a resposta crua do classificador

Quando o classificador não acha o JSON, o Dify joga fora o que o modelo respondeu (nem os Logs mostram). Este teste manda ao mesmo modelo, com os mesmos parâmetros, exatamente as mensagens que o classificador monta, e mostra a resposta como ela veio. Usa um app separado no Dify, "Diagnóstico do classificador (kit)", e gasta cota.

As opções só valem para este teste: o Bot STJ não muda. Outro modelo precisa estar cadastrado no provedor do Dify.

Comparar modelos no classificador

Manda as mesmas perguntas, do mesmo jeito que o classificador do Bot STJ, para cada modelo marcado (de todas as contas conectadas no Dify) e mostra o que cada um respondeu. Todos com os mesmos parâmetros: a temperatura do nó e, só no gpt-oss, reasoning_effort=low. O Bot STJ não muda. Cada pergunta gasta cota.
